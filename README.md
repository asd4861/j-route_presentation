### 📖 プロジェクト概要 (Project Overview)
- **プロジェクト名**: J-Route
- **概要**: AIを活用したオーダーメイド型日本旅行日程の提案および旅行便利ユーティリティを提供するプラットフォーム
- **主な目的**: 日本旅行者のための統合旅行情報および便利なサポート機能の提供

---

### 🛠 担当役割および開発内容 (My Role & Contributions)
**[サイドバー統合ユーティリティモジュールの開発]**
- **航空券検索機能**: リアルタイムのフライト日程および価格情報照会ユーティリティの実装
- **宿泊情報照会**: 目的地に応じたおすすめホテルデータの連携およびUI構築
- **天気情報サービス**: 旅行地域のリアルタイム・予報天気データの提供
- **予算管理ユーティリティ**: 為替計算および旅行支出の予算トラッキング機能の実装

- **Frontend**: HTML5, CSS3, JavaScript
