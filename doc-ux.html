主要 Thymeleaf コンポーネント一覧
コンポーネント / テンプレートパス説明
Layout 共通レイアウトlayout/default.htmlヘッダー・フッターを含む全ページ共通枠。Thymeleaf Layout Dialect使用。
Page メインページindex.htmlサービス紹介・ナビゲーション。ログイン状態によってUIを切り替え。
Page ログインuser/login.htmlSpring Security loginProcessingUrl="/loginProc" に接続。エラー時メッセージ表示。
Page 会員登録user/register.htmlID・パスワード・ニックネーム入力。バリデーション後DBへ保存。
Page マイページuser/mypage.html保存した旅行プランと各カテゴリのウィッシュリストをタブで表示。
Page AIプランナーplanner/form.html地域・日数・テーマの入力フォーム。送信後AI生成ページへ遷移。
Page グルメ探索gourmet/index.htmlGoogle Maps SDKを埋め込み。Places API検索結果をマーカー＆カードで表示。
Page 天気予報weather/index.html都市名入力→Open-Meteo呼出→Chart.js気温グラフ＆服装提案表示。
Page 掲示板board/list.html旅行記事一覧。地域・期間でのフィルタリング。
Fragment ウィッシュリストボタンfragments/wishBtn.html各ページのお気に入りボタン。AJAX POSTでトグル処理を実装。
